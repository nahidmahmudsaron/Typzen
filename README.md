## 🌸 About Typzen

**Typzen** is a simple, beautiful and user-friendly typing speed test website.

It provides a distraction-free environment where users can practice typing, measure their speed, improve accuracy and track their personal best.

Unlike complicated typing platforms, Typzen focuses on simplicity, comfort and a delightful typing experience.

## ✨ Features

- **Ghost Text Typing:** Type directly while following the displayed reference text.
- **Live WPM:** Track your typing speed in real time.
- **Accuracy Tracking:** See how accurately you type.
- **Multiple Durations:** Choose between 15, 30 and 60 seconds.
- **Smart Focus Line:** Automatically follows your typing progress.
- **Character Highlighting:** Different visual feedback for correct and incorrect characters.
- **Personal Best:** Save your highest typing speed locally.
- **Mistake Insights:** Identify commonly mistyped characters.
- **Sound Effects:** Optional subtle typing and completion sounds.
- **Light & Dark Mode:** Choose your preferred appearance.
- **Responsive Design:** Enjoy Typzen on desktop, tablet and mobile.

## 🎨 Design Philosophy

Typzen is designed around three simple ideas:

- Minimalism — Only essential features.
- Comfort — A calm and beautiful interface.
- Progress — Make typing practice enjoyable.

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage
- Web Audio API (where used for sound effects)

No backend, database, Firebase or external API is required.

## 🚀 Getting Started

### Run Locally

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder.

3. Open the HTML file in your browser.

### Blogger Installation

Typzen is designed to be compatible with Google Blogger.

1. Open your Blogger Dashboard.
2. Navigate to **Theme**.
3. Select the dropdown menu beside Customize.
4. Choose **Restore**.
5. Upload the `Typzen-Blogger-Theme.xml` file.
